# Gestalt v0.1 Conformance Matrix

This matrix is the final evidence map for every contract ID published in the
[v0.1 contract index](./README.md). A row is published only when its claim has
an implementation and an enforcing test. Test names refer to files under the
workspace crate `tests/` directories unless a module is named explicitly.
